# Типовой алгоритм внутреннего пентеста

Этот каталог содержит канонический регламент в формате редактора
`drakon.tech.desktop`. Это проектирование и контроль полноты действий, а не
средство автоматического выполнения команд.

Исполнимая схема 08 находится отдельно в `../workflows/08-no-creds-siluet.drakon`.
Копия `08-no-creds-siluet.drakon` в этом каталоге служит только исходным
макетом для общего регламента и не загружается воркёром.

## Открытие проекта

1. Установите `drakon.tech.desktop` на рабочей Kali в отдельный каталог.
2. Откройте файл `typovoy-vnutrenniy-pentest.dtproj` из этого каталога.
3. Главная схема `00-siluet.drakon` показывает порядок этапов. Каждый этап
   открыт отдельным файлом, чтобы схема оставалась читаемой.

Файлы `.drakon` — JSON. Их можно проверять средствами Git и изменять без
графического окна, но визуальную проверку нужно выполнять в редакторе перед
утверждением новой версии.

На `kali-vm-main` редактор запускается командой `drakontech`. Он установлен
отдельно от панели в `/opt/drakon-tech.desktop`; запуск от root выполняется с
отключённой песочницей Electron, заданной внутри команды запуска.

Для новой Kali не повторяйте установку вручную. Из корня этого репозитория
запустите `sudo bash tools/install-drakontech.sh --desktop-user kali`.

## Правила применения

- Нельзя начинать подключение, обнаружение или проверку без записанных scope,
  списка разрешённых VPN и CIDR.
- Push-route VPN не является разрешением на сканирование.
- Режим `discover` — первый массовый проход; полный TCP-скан допускается только
  для подтверждённых живых целей и согласованных CIDR.
- Любая рискованная либо учётная проверка требует отдельного условия запуска,
  записи результата и доказательства.
- Отсутствие результата не является успехом: требуется либо доказательство,
  либо причина блокировки, либо статус «неприменимо».

## Состав

| Файл | Назначение |
|---|---|
| `00-siluet.drakon` | главный порядок и точки перехода |
| `01-scope.drakon` | разрешение, границы и ограничения |
| `02-vpn.drakon` | VPN и контрольный маршрут Kali |
| `03-discovery.drakon` | обнаружение хостов и подсетей |
| `04-services.drakon` | сервисы, классификация и выбор ветки |
| `05-proverki.drakon` | безучётные, учётные и уязвимостные проверки |
| `06-dokazatelstva.drakon` | доказательства, triage и загрузка |
| `07-zavershenie.drakon` | контроль полноты и завершение |
| `08-no-creds-siluet.drakon` | макет подробного силуэта этапа без учётных данных; не исполняется |

Связь с MITRE: техника и команда выбираются только на шаге `05-proverki` после
выполнения предусловий. Справочник MITRE остаётся источником команд, а этот
проект определяет их допустимую последовательность.
